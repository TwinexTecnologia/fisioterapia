Como utilizar

VERDE
PERGUNTA, mostra o que você deve perguntar para o corpo do paciente. Qual posição avaliar, ou movimento.
LARANJA
RESPOSTA, clicando nele você irá para o próximo passo.
BRANCO
ORIENTAÇÃO, indica o que deve ser feito.
CINZA
INTERPRETAÇÃO, revela a síndrome que foi encontrada. Usado também para orientar o MOVIMENTO DE LIMPEZA.
PRETO
ÁREAS, clicando aqui você irá para a área correspondente: Área Secundária, Área Terciária e Movimento de Limpeza.
🏠
AVALIAÇÃO INICIAL, sempre que quiser voltar para a avaliação inicial clique aqui.

🍎 Na parte superior ficará salvo para você o caminho que você percorreu para chegar até ali.

🍎 Após a correção, volte para a avaliação inicial. Recomece até chegar na opção de alta.
